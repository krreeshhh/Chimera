# Chimera

**Chimera** is a production-ready, self-hosted image-processing API and Telegram bot that performs genuine **local AI background removal** (without relying on remove.bg or any other third-party paid APIs) and image format conversion. 

Built using **Next.js**, **Sharp**, and **ONNX Runtime (via Hugging Face Transformers.js)**, the system is designed to be fully **stateless**, making it compatible with ephemeral environments like Vercel Serverless Functions.

---

## Features
* **Genuine Local AI Background Removal**: Uses the state-of-the-art **BRIA RMBG-1.4** model running locally via ONNX Runtime on your own server. No API keys or external queries are sent to third parties.
* **Format Conversion**: Support for converting to and from `JPEG`, `PNG`, `WebP`, and `AVIF` using the high-performance `Sharp` processing library.
* **Stateless Operation**: No local database or storage requirement. Conversational menus in Telegram are fully stateless using deep linking and replies.
* **Ephemerally Cache-Optimized**: Serverless-ready model caching strategy that reads from `/tmp` on warm starts to execute background removals in sub-second times.
* **Interactive Telegram Bot**: Supports inline menus for operation options (Remove Background, Convert, and Convert + Remove BG) with custom solid or transparent background selections.
* **Exposed REST API**: Fully exposed HTTP POST endpoints for simple application integration.
* **Strict Security Protections**: Validates magic-bytes, input dimensions, rate limits requests, and enforces size constraints.

## Tech Stack
* **Framework**: Next.js 15 (App Router, Serverless API Routes)
* **Image Processor**: Sharp
* **AI Model Engine**: ONNX Runtime via `@huggingface/transformers`
* **AI Model**: `briaai/RMBG-1.4` (gated but free for non-commercial/academic use under CC BY-NC-SA 4.0)
* **Telegram bot**: Telegraf

## Environment Variables

Copy `.env.example` to `.env` and set up your variables:

```bash
cp .env.example .env
```

* `TELEGRAM_BOT_TOKEN`: The API token generated by @BotFather.
* `TELEGRAM_WEBHOOK_SECRET`: A secure random secret string to verify incoming Telegram requests.
* `MAX_FILE_SIZE_MB`: Maximum input file size allowed (default: `20`).
* `MAX_IMAGE_PIXELS`: Maximum pixel count allowed to prevent memory exhaustion (default: `4194304`, which is 4 Megapixels / 2000x2000).

## REST API Documentation

### 1. Health Status
`GET /api/health`
* **Description**: Returns the service status.
* **Example**:
  ```bash
  curl -X GET http://localhost:3000/api/health
  ```
* **Response**:
  ```json
  {"ok": true, "service": "chimera"}
  ```

### 2. Convert Format
`POST /api/convert`
* **Description**: Convert an image format.
* **Fields**:
  * `image`: Binary image file (multipart/form-data)
  * `format`: Target format (`jpeg`, `jpg`, `png`, `webp`, `avif`)
  * `quality`: Compression quality (`1` to `100`, default `85`)
* **Example**:
  ```bash
  curl -X POST http://localhost:3000/api/convert \
    -F "image=@my-photo.jpg" \
    -F "format=webp" \
    -F "quality=80" --output output.webp
  ```

### 3. Remove Background
`POST /api/remove-background`
* **Description**: Removes the background of the image.
* **Fields**:
  * `image`: Binary image file (multipart/form-data)
  * `background`: Background fill style (`transparent`, `white`, `black`, or a HEX value like `#ff0000`)
* **Example**:
  ```bash
  curl -X POST http://localhost:3000/api/remove-background \
    -F "image=@my-photo.jpg" \
    -F "background=transparent" --output transparent-result.png
  ```

### 4. Combined Processing
`POST /api/process`
* **Description**: Runs both background removal and format conversion in a single pipeline.
* **Fields**:
  * `image`: Binary image file (multipart/form-data)
  * `operation`: `convert` | `remove-background` | `convert-and-remove-background`
  * `format`: Target format (`png`, `webp`, `jpeg`, `avif`)
  * `background`: Background fill (`transparent`, `white`, `black`, or `#hex`)
  * `quality`: Compression quality (`1` to `100`, default `85`)
* **Example**:
  ```bash
  curl -X POST http://localhost:3000/api/process \
    -F "image=@my-photo.jpg" \
    -F "operation=convert-and-remove-background" \
    -F "format=webp" \
    -F "background=white" --output final-result.webp
  ```

## Telegram Bot Hook Setup

1. Message [@BotFather](https://t.me/BotFather) on Telegram and create a bot using `/newbot` to get your `TELEGRAM_BOT_TOKEN`.
2. Set up the webhook by sending a request to Telegram (replace `<TOKEN>` and `<DOMAIN>`):
   ```bash
   curl -X POST "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook" \
     -H "Content-Type: application/json" \
     -d '{"url": "https://<YOUR_VERCEL_DOMAIN>/api/telegram/webhook", "secret_token": "<TELEGRAM_WEBHOOK_SECRET>"}'
   ```
3. Send an image to your bot, choose your actions on the inline keyboard, and receive your processed image!

## Limitations
* **Serverless Cold Starts**: On a cold start of a Vercel Serverless Function, downloading the model weights (~44MB) can add 1-2 seconds of latency. Warm instances will bypass this.
* **Memory Limits**: Extremely large images (exceeding 4MP) may run into memory constraints in serverless functions.
* **CPU Inference**: Running AI inference on serverless CPUs takes ~3-5 seconds. If you need sub-second response times under heavy loads, configure a GPU worker (refer to [ARCHITECTURE.md](ARCHITECTURE.md)).
